# LINEUP LAB · 点位实验室

《无畏契约（VALORANT）》常用道具点位整理站 —— 《新生实践课》网页设计作业。

- **5 张地图**：亚海悬城 / 源工重镇 / 隐世修所 / 莲华古城 / 日落之城
- **30 名英雄**：覆盖决斗者、控场者、先锋、哨卫四个定位
- **80 组点位**：每个点位都拆成「站位 / 瞄点 / 落点 / 时机」四段说明，并配一张原创战术示意图

## 目录结构

```
├─ README.md             本文件

│  └─ js/site.js         全站交互（原生 JS，无依赖）
└─ image/                图片素材
   ├─ maps/              地图全景图、俯视图
   ├─ agents/            英雄立绘、半身像、背景图、方形头像

```

所有页面之间的链接、图片引用**全部使用相对路径**，可整个文件夹拷贝到任意位置、直接用浏览器打开，也可以直接上传到 GitHub Pages。

## 使用方法

1. 打开 `index.html`（双击即可，无需搭建服务器）。
2. 在主页点击任意地图卡片进入该地图的点位页。
3. 在地图页左侧（手机端为上方横排）点击英雄立绘即可切换：右侧内容、整块背景与主题色都会跟着变化。
4. 也可以直接用地址栏锚点定位到某个英雄，例如 `web/ascent.html#sova`。
5. 顶部导航的「角色速查」按定位列出了全部 30 名英雄，点击卡片会跳到对应地图并自动选中该英雄。

## 用 Dreamweaver 打开

1. Dreamweaver →「站点」→「新建站点」，站点名称随意。
2. 本地站点文件夹选择本 `MyWeb` 文件夹。
3. 在「文件」面板中双击 `index.html` 即可编辑；CSS、JS、图片都在 `web/`、`image/` 下。

## 技术说明

- HTML5 + CSS3 + 原生 JavaScript，**不依赖任何第三方框架、CDN 或外部字体**，断网也能完整显示。
- 响应式布局：桌面双栏（左侧竖排立绘 + 右侧点位）、平板与手机单栏（立绘改为横向滑动）。
- 无 JS 时：所有英雄的点位会依次展开显示，内容不会丢失；`IntersectionObserver` 不可用时自动关闭滚动动画。
- 主题色：深色底 `#0F1923` + 亮红 `#FF4655`，锐利斜切几何与四角框线；定位色分别为决斗者红、控场者青、先锋橙、哨卫蓝。
- 交互：立绘切换（含键盘 ↑↓）、地图卡片悬停、滚动出现动画、角色速查按定位筛选、回到顶部。
